# 📝 TextUtils

TextUtils is a simple React-based text utility app that allows users to analyze and manipulate text.  
It includes features such as case conversion, word count, character count, and a light/dark mode toggle.  

---

## 🚀 Features

- **Text Analysis** – Count words, characters, and estimate reading time.
- **Case Conversion** – Convert text to uppercase, lowercase, or clear it entirely.
- **Dark/Light Mode** – Switch between light and dark themes for a better reading experience.
- **Alert Messages** – Displays alerts for user actions (e.g., dark mode enabled).
- **Responsive Navbar** – Navigate between Home and About pages.
- **React Router Integration** – SPA navigation without page reloads.

---

## 📦 Tech Stack

- **React.js** – Frontend library
- **Bootstrap 5** – Styling and responsive layout
- **React Router DOM (v5)** – Client-side routing
